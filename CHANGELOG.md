# Changelog

- Added capability tunnel
  - Added to creative menu
  - Added item support
  - Item form holds side last set in NBT
- Added fluid and energy support to the tunnel
  - Ensured normal limits still apply for energy and fluid transfer
  - Placed block against a tunnel or machine face updates the tunneled side
- Fixed world save bug causing chunks to never finish unloading
- Set tunnels to claim a side of the machine for a 1:1 correspondence
  - Picks first free side on place, failing to place if no free sides remaining
- Ctrl + mouse wheel cycles through free sides when looking at a tunnel
  - Direction depends on which way you scroll
- Shift + left-click with an empty hand to pick up a tunnel
- Creative middle-click grabs a blank tunnel, ctrl + middle-click copies its side data
- Added Jade tooltip support
  - Works from either end: a tunnel shows its machine face, a machine face shows its tunnel
  - Shows the current face and how many sides are used
  - Embeds the tunneled block's tooltip into the tunnel's tooltip
  - Added config option to disable ghost block "hack" used for embedding the tooltip
  - Shows if tunneled side is empty or unloaded
